# 久留美上班赚钱器

桌宠陪你上班，显示工资进度，下班播放金币雨，并积累可供后续购物使用的虚拟余额。

## 下载 Windows 版

[打开下载页面](https://github.com/Ray-21912268/kurumi-workpet/releases/tag/windows-v1.1.0)

- 推荐：下载 `KurumiWorkpet-1.1.0-windows-x64.exe`，复制到固定文件夹后双击运行。
- 备用：下载 `KurumiWorkpet-1.1.0-windows-x64.zip`，完整解压后运行“久留美上班赚钱器.exe”；保留旁边的 DLL 和资源。
- 源码：下载 `KurumiWorkpet-1.1.0-windows-source.zip`，包含 Windows 完整源码、资源、测试与构建说明。

适用 Windows 10 / 11，Intel 或 AMD 64 位电脑。程序包含运行环境，无需另装 Node.js 或 .NET，无需管理员权限。

## 使用

首次填写月薪并保存。右下角通知区域双击久留美图标打开设置，右键提供显示／隐藏、点击穿透、金币雨和退出。

支持月薪、上下班、午休、每周排班、日期修改、2026 年中国假期及调休、按排班或仅运行时累计。计时按北京时间。

桌宠可拖动和调整大小；贴近屏幕上下左右四边自动隐藏金额面板，鼠标进入角色图像后显示，移到面板可继续操作。

工资与虚拟余额保存在当前电脑 `%APPDATA%\KurumiWorkpet`，不需要联网。程序包没有实际工资或余额数据。首版提供钱包接口，暂不包含商店。
